# AI Usage

AI coding assistants (Codex) were used throughout the development process as a coding assistant.

## Development Workflow

1. **Project Planning:** Initially created `AGENTS.md` and `SKILL.md` files to provide project requirements, coding guidelines, and resume-analysis instructions to the AI agent.

2. **Architecture Planning:** Provided Codex with a prompt to read these instruction files, understand the requirements, suggest the architecture, dependencies, folder structure, database schema, and security requirements before implementation.

3. **Initial Implementation:** Used Codex to assist with the initial project implementation. However, the initial structure had some issues and did not work as expected.

4. **Code Refactoring:** Reviewed the generated code and decided to reorganize the backend using the MVC pattern, separating models, controllers, routes, and middleware.

5. **Implementation and Debugging:** Provided the project requirements and existing code to Codex for assistance with refactoring, implementing features, and fixing errors.

6. **Code Review:** Reviewed and modified the generated code, then verified the application through manual testing, TypeScript checks, and production builds.

## Responsibility

AI was used to improve development speed and assist with problem-solving. Architecture decisions, code review, integration, testing, and final implementation were handled by the developer.
